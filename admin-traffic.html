How to read these numbers

Visitors are estimated using a random ID saved in the browser. Clearing browser storage or using another device can count as a new visitor. Sessions expire after 30 minutes without activity. Your signed-in owner activity is excluded by default.

Checkout starts and paying users come from the server and Stripe. Test-mode subscriptions are excluded. Active subscribers is the current total; new paying users is measured within the selected period. Counts are activity totals, not a tracked user-by-user conversion funnel.
